# SEO Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make iamrawtion.github.io fully indexable by Google so recruiters searching for remote DevOps consultants/trainers land on the portfolio.

**Architecture:** Extend the existing `generate-feeds.js` Node.js build script to pre-render all 65 blog posts as static HTML files at `blogs/<slug>.html`. Add a dedicated `consulting.html` page with recruiter-targeted keywords. Improve meta tags on `index.html`. All changes are pure HTML/CSS/JS — no framework, no new runtime dependency except `marked` (npm package for markdown-to-HTML conversion).

**Tech Stack:** Node.js (build script), vanilla HTML/CSS/JS, `marked` npm package for markdown parsing, JSON-LD structured data, Open Graph meta tags.

- [ ] **Step 1: Add the blog HTML generation block to generate-feeds.js**

At the end of `generate-feeds.js` (after the `feed.xml` write block), add:

```js
// --- static blog HTML pages ---
let generated = 0;
for (const blog of blogs) {
  const mdPath = `blogs/${blog.file}`;
  if (!fs.existsSync(mdPath)) {
    console.warn(`⚠️  skipping ${blog.id} — ${mdPath} not found`);
    continue;
  }
  const raw = fs.readFileSync(mdPath, 'utf8');
  // Strip YAML frontmatter (--- ... ---)
  const body = raw.replace(/^---[\s\S]*?---\n/, '');
  const bodyHtml = marked(body);
  const html = blogPostHtml(blog, bodyHtml);
  fs.writeFileSync(`blogs/${blog.id}.html`, html);
  generated++;
}
console.log(`✅ static blog pages — ${generated} HTML files written to blogs/`);
```
